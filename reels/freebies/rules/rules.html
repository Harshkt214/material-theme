Mere Trading Rules

Rules likhe hue hon to galti chhupti nahi. Har dabbe mein apna rule likho, example sirf idea ke liye hai. Phir print karke screen ke paas lagao.
KAISE BHARORule chhota, saaf aur check hone layak ho. "Dhyaan se trade karunga" rule nahi hai. "Ek din mein max 3 trade" rule hai.
KYUNMark Douglas (The Disciplined Trader): log rules isliye nahi likhte kyunki rules unhe accountable banaate hain. Wahi to chahiye.
1
Ek trade mein kitna risk RISK
Example: Ek trade mein capital ka 1% se zyada nahi. ₹1,00,000 capital = max ₹1,000 risk per trade. (Bahut se traders 1 se 2% rakhte hain. Ye common practice hai, niyam nahi.)
MERA RULE
2
Entry kab lunga ENTRY
Example: Sirf mera likha hua setup (jaise breakout ke baad retest). Setup nahi = trade nahi. Candle bhaag gayi to chase nahi karunga.
MERA RULE
3
Stop loss EXIT · LOSS
Example: SL entry se pehle tay, aur broker mein lagaya hua, dimaag mein nahi. Loss mein SL kabhi door nahi khiskaunga.
MERA RULE
4
Profit mein exit EXIT · TARGET
Example: Target entry se pehle likhunga (jaise 2R). Target aaya to plan ke hisaab se nikalunga, "thoda aur" nahi.
MERA RULE
5
Ek din mein max trades OVERTRADING
Example: Ek din mein max 3 trade. Sideways ya boring din par 0 trade bhi theek hai. No setup = no trade.
MERA RULE

Band karne ke rules

6
Daily max loss DAILY LIMIT
Example: Din ka loss ₹2,000 (capital ka 2%) pahunchte hi aaj trading band. App band, chart band. Kal naya din.
MERA RULE
7
Loss ke baad NO REVENGE
Example: Har loss ke baad 15 minute screen band. Gussa ho to us din ka agla trade nahi. Market se "badla" nahi lena.
MERA RULE
8
Loss wali position mein add nahi NO AVERAGING DOWN
Example: Loss wali position mein kabhi aur nahi kharidunga. Add sirf profit wali position mein, wo bhi plan ke hisaab se. (Tom Hougaard, Best Loser Wins)
MERA RULE
